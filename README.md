# Libreta

Tablero personal minimalista.

## Por ahora

- Un tablero con fondo de puntos
- Colocar notas (botón **Nota** → clic en el tablero)
- Mover notas arrastrando la cabecera
- Escribir en cada nota
- Zoom con la rueda del ratón
- Pan con el botón central del ratón
- Guardado local en el navegador

## Desarrollo

```bash
pnpm install
pnpm dev
```

Abre [http://localhost:3000](http://localhost:3000).
